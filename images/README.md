Place the photo files you want the invitation to use in this folder.

- Recommended filenames:
  - `photo1.jpg` — main hero image (shown first)
  - `photo2.jpg` — secondary image (rotates in gallery)

After copying the images here, reload the page (or re-run the app) so the browser picks up the new local images.

If you prefer different names, open `config.js` and update the `galleryPhotos` array to match your filenames.
